# 综述类型与协议

## 类型选择

| 类型 | 适用问题 | 最低方法要求 | 主要输出 |
|---|---|---|---|
| 叙述综述 | 解释概念、机制或领域演进 | 声明检索来源、范围和选择逻辑 | 主题式综合 |
| 系统评价 | 回答边界清晰、可复核的问题 | 预设协议、完整检索、双阶段筛选、偏倚评价、PRISMA | 系统评价正文与附录 |
| 范围综述 | 描述证据分布、概念和研究类型 | 范围协议、广泛检索、PRISMA-ScR | 证据地图 |
| 快速综述 | 在时限内回答决策问题 | 明示简化环节及其偏倚 | 快速证据报告 |
| Umbrella Review | 综合既有系统评价 | 评价纳入综述质量和重叠 | 综述层证据综合 |
| Meta-analysis 导向 | 量化可合并效应 | 预设结局、效应量、异质性和统计计划 | Evidence Set，转 F-06 计算 |

## Review Protocol 必填

`protocol_id`、版本、状态、综述类型、研究问题/PICOS、目标读者、数据库、补充来源、检索截止日、语言、研究设计、纳入标准、排除标准、主要/次要结局、筛选流程、数据提取字段、质量评价工具、综合方法、注册信息、偏离协议记录。

## 选择质量评价工具

- RCT：RoB 2。
- 非随机干预：ROBINS-I。
- 队列/病例对照：NOS 或 JBI 对应清单。
- 诊断准确性：QUADAS-2。
- 系统评价：AMSTAR 2 或 ROBIS。
- 定性研究：CASP/JBI。

不要把量表总分机械转换为“高质量”。保留领域级判断和理由。

## 协议确认

正式检索前冻结协议版本。变更数据库、纳排标准、主要结局或评价方法时登记偏离原因并创建新版本。
