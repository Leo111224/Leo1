# 投稿包与接收后流程规则

## 投稿包最小清单

Manuscript、Title Page、Cover Letter、Figures、Tables、Supplement、References、Ethics Statement、COI Statement、Funding Statement、Author Contribution、Data Availability、Reporting Checklist。

## 投稿系统

Agent 可生成操作清单和字段草案，但不得默认登录、提交、支付或签署。外部系统操作属于 R3。

## 决定信解析

分类：accept、minor revision、major revision、reject and resubmit、reject、transfer。解析编辑要求、审稿人问题、截止日期、文件要求和策略风险。

## 接收后流程

检查版权协议、OA/APC 费用、发票来源、清样校对、作者信息、图表质量、Online First、正式卷期页码和数据库收录状态。
