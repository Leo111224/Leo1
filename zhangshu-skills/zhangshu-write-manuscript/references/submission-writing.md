# 投稿文书与审稿回复

## Cover Letter

必须包含文章题目、文章类型、核心贡献、适配期刊理由、伦理/利益冲突声明占位、通讯作者信息。不得承诺录用概率或夸大创新。

## 审稿回复矩阵

每条意见记录：

`comment_id`、`reviewer`、`comment_text`、`category`、`required_action`、`upstream_skill`、`artifact_needed`、`response_draft`、`status`。

- 研究设计：转 F-03
