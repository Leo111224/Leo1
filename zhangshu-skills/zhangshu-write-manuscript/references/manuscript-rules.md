# 论文正文写作规则

## 必须追溯

- 背景、现状、争议和研究空白必须绑定 `evidence_ref`。
- 统计数值、P 值、区间估计、模型结果、样本量必须绑定 `result_ref`。
- 图表说明必须绑定 `figure_ref` 和 `result_ref`。

## IMRAD 分工

| 章节 | 来源资产 | 禁止事项 |
|---|---|---|
| Title | 研究设计、对象、核心变量 | 夸大因果或临床结论 |
| Abstract | Protocol、Verified Result、Manuscript | 填入未验证数值 |
| Introduction | Evidence Set、Synthesis Map | 编造“首次”“唯一” |
| Methods | Protocol、Analysis Plan | 事后美化方案 |
| Results | Verified Result、Figure Asset | 选择性隐藏不显著结果 |
| Discussion | Evidence Set、Verified Result | 把相关性写成因果 |

## 报告规范

根据研究类型提示 CONSORT、STROBE、PRISMA、TRIPOD、STARD、CHEERS 等报告规范；缺少必要项目时生成 compliance gap，不直接伪造。
