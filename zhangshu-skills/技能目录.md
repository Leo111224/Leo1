# 掌术 AI Skills 目录

本目录按“总编排 + 12 个业务 Skill”组织，覆盖临床科研从选题到接收后管理的完整工作流。

| Skill | 对应任务 | 核心交付 |
|---|---|---|
| `zhangshu-research-orchestrator` | 总编排 | 入口节点识别、任务路由、确认点、产物衔接 |
| `zhangshu-plan-topic` | F-01 选题规划 | Research Brief、PICOS 草案、选题方案 |
| `zhangshu-review-literature` | F-02 文献综述 | Review Protocol、Search/Screening Log、Evidence Set、Review Package |
| `zhangshu-design-study` | F-03 研究设计 | Study Design Package、Sample Size Report、CRF、Protocol |
| `zhangshu-clean-clinical-data` | F-04 数据清洗 | Data Quality Report、Cleaning Plan、新 Dataset Version |
| `zhangshu-route-statistics` | F-05 算法推荐 | 方法推荐卡、Analysis Plan |
| `zhangshu-run-statistical-analysis` | F-06 统计分析 | Analysis Run、Environment Report、Verified Result、可复现代码包 |
| `zhangshu-create-scientific-figures` | F-07 统计绘图 | Figure Asset、图注、绘图代码、导出包 |
| `zhangshu-write-manuscript` | F-08 报告生成 | Manuscript、Cover Letter、审稿回复、合规声明、导出包 |
| `zhangshu-format-references` | F-09 文献格式化 | Reference Set、引用冲突报告、目标期刊格式 |
| `zhangshu-match-journals` | F-10 期刊推荐 | Journal Candidates、Submission Plan、投稿包检查、接收后清单 |
| `zhangshu-ethics-registration` | F-11 伦理注册 | Ethics Package、知情同意、隐私治理、注册字段草案 |
| `zhangshu-manage-study-execution` | F-12 研究执行管理 | Recruitment Plan、Follow-up Schedule、Monitoring Report |

## 使用顺序

1. 用户目标不明确、跨越多个阶段或从中间材料进入时，先调用 `zhangshu-research-orchestrator`。
2. 用户目标明确时，可直接调用对应业务 Skill；业务 Skill 仍需检查必要上游资产。
3. R2 数据/计算/方案变更和 R3 正式导出/外部动作必须获得明确确认。
4. 正式统计数值只能来自 `Verified Result`。
5. 外部系统动作，如伦理平台注册、投稿系统提交、APC 支付、版权签署、患者联系，默认只生成清单或草案；自动执行需要连接器和 R3 强确认。

## 论文流程调用顺序

> F 编号是能力编号，不等于真实业务发生顺序。汇报、路由和 Agent 编排应优先按照论文/临床科研流程展示。

| 流程顺序 | Skill 编号 | 业务节点 | 说明 |
|---:|---|---|---|
| 1 | F-01 | 选题规划 | 从临床问题、领域热点和数据条件形成 Research Brief。 |
| 2 | F-02 | 文献综述 | 补齐证据基础、研究空白和综述材料。 |
| 3 | F-03 | 研究设计 | 形成 Protocol、样本量、CRF、偏倚控制和统计框架。 |
| 4 | F-11 | 伦理注册 | 在研究正式执行前准备伦理、知情同意、隐私治理和注册字段。 |
| 5 | F-12 | 研究执行管理 | 管理招募、入组、随访、CRF 质控和方案偏离。 |
| 6 | F-04 | 数据清洗 | 对研究数据做质量画像、清洗规则和版本治理。 |
| 7 | F-05 | 算法推荐 | 根据设计和数据推荐统计方法并形成 Analysis Plan。 |
| 8 | F-06 | 统计分析 | 执行分析、验证结果并生成可复现代码包。 |
| 9 | F-07 | 统计绘图 | 生成论文图表、图注和 Figure Asset。 |
| 10 | F-08 | 报告生成 | 生成 IMRAD、声明、投稿信和审稿回复。 |
| 11 | F-09 | 文献格式化 | 修复、去重、校验并格式化参考文献。 |
| 12 | F-10 | 期刊推荐 | 完成选刊、投稿包、改投和接收后清单。 |

## 目录说明

每个 Skill 通常包含：

- `SKILL.md`：触发说明、工作流、边界和输出契约。
- `agents/openai.yaml`：Skill 列表显示和默认提示。
- `references/`：按需读取的领域规则。
- `scripts/`：确定性校验、计算或审计脚本。
- `assets/`：结构化输出模板。
