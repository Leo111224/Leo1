# 统计路由规则

## 硬约束顺序

1. 研究设计和分析目标。
2. 结局类型：连续、二分类、计数、时间结局、诊断指标。
3. 数据结构：独立、配对、重复测量、聚类、删失。
4. 样本量、事件数和每参数事件数。
5. 方法前提和算法注册表状态。

## 常见映射

- 二分类结局：Logistic 或适用的广义线性模型。
- 时间结局且存在删失：KM/log-rank、Cox 或适用生存模型。
- 观察性治疗效果：先检查混杂，再考虑 PSM/IPTW/加权回归。
- 诊断检测：2×2 指标、ROC/AUC、校准和阈值选择。
- 多研究合并：效应量统一、异质性、固定/随机效应和偏倚检查。

所有推荐必须说明不适用条件和敏感性分析。
