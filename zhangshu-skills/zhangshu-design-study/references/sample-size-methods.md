# 样本量方法

## 基础方法

| 场景 | 关键参数 | 输出 |
|---|---|---|
| 单率精度 | 预期率、允许误差、置信水平 | 总样本量 |
| 两独立率比较 | 两组率、α、把握度、分配比 | 每组及总样本量 |
| 两独立均数比较 | 差值、标准差、α、把握度、分配比 | 每组及总样本量 |
| 生存两组比较 | HR、事件分配、α、把握度、入组/随访、失访 | 事件数及估计样本量 |
| 诊断准确性 | 灵敏度、特异度、精度、患病率 | 患病/非患病例数及总量 |
| 患病率调查 | 预期患病率、绝对精度、设计效应 | 总样本量 |

## 必须记录

方法 ID 和版本、公式/软件、单双侧、α、把握度、效应量及来源、组间分配、失访/无效率、设计效应、事件率、舍入规则和敏感性场景。

## 不可简化的情况

非劣效/等效、集群随机、交叉、重复测量、序贯/自适应、多重主要结局、复杂抽样、预测模型开发、外部验证和缺失数据膨胀需要专门方法或统计师复核。EPV=10 只能作为历史启发式，不能作为正式预测模型样本量依据。

参数缺少可靠来源时计算至少三个场景并保持 `PROVISIONAL`，不得给出唯一“所需样本量”。
