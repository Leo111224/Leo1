# 研究设计决策树

## 先判定研究目标

| 目标 | 核心问题 | 优先设计候选 |
|---|---|---|
| 疗效/安全性 | 主动分配干预是否改变结局 | RCT；无法随机时非随机干预研究 |
| 病因/风险因素 | 暴露与结局是否关联 | 队列；罕见结局可病例对照 |
| 诊断准确性 | 指标检测相对参考标准表现如何 | 横断/队列式诊断准确性研究 |
| 预后因素 | 基线因素是否关联未来结局 | 预后队列 |
| 预测模型 | 多变量组合能否预测个体风险 | 模型开发、外部验证或更新队列 |
| 患病率/现况 | 某时点疾病或特征分布如何 | 横断面研究 |
| 描述罕见现象 | 临床特征和过程是什么 | 病例系列 |
| 常规诊疗效果 | 真实世界路径中的比较效果/安全性 | 目标试验模拟、回顾/前瞻队列 |

## 时间和分配规则

- 主动分配且随机：随机对照试验。
- 主动分配但不随机：非随机干预研究；明确分配机制和混杂风险。
- 按暴露状态向未来观察：前瞻性队列。
- 使用既往暴露和结局记录：回顾性队列。
- 从结局状态抽样并回溯暴露：病例对照。
- 同一时点测量暴露和结局：横断面；通常不能确认时间顺序。
- 检测结果与独立参考标准比较：诊断准确性。
- 预测时间结局：明确预测时点、预测窗口和删失处理。

## 路由输出

每个候选记录：`design_id`、研究目标、适用条件、数据需求、时间方向、对照策略、可识别效应、主要偏倚、报告规范（SPIRIT/CONSORT/STROBE/STARD/TRIPOD/RECORD 等）、可行性和排除原因。

不要仅凭关键词自动冻结设计；资源、伦理和数据生成机制必须参与判断。
