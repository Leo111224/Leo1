# 科研图表规则

## 图形选择

- 时间结局：KM、累积发生率、森林图。
- 回归效应：森林图、系数图。
- 诊断性能：ROC、校准、决策曲线。
- 高维差异：火山图、热图。
- 模型解释：变量重要性、SHAP，但必须说明模型和数据版本。

## 视觉完整性

保存轴范围、变换、过滤、分组、颜色和标注规则。任何数据过滤都必须预先定义并在图注披露。

## 可访问性

使用色盲安全配色、足够对比度、可读字体、黑白打印可区分线型，并提供替代文本。

## Figure Manifest

figure_id、plot_spec_version、result_refs、code_hash、runtime、style_version、export_files、file_hashes。
