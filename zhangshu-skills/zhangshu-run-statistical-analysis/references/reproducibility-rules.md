# 统计可复现与代码审计规则

## 环境检查

记录操作系统、执行器镜像、R/Python 版本、包版本、随机种子、CPU/GPU、内存限制、运行时间、输入数据版本和输出目录。

## 脚本审计

重点检查：

- 是否硬编码本地路径；
- 是否在分析脚本中静默修改原始数据；
- 是否缺少随机种子；
- 是否删除或过滤不显著结果；
- 是否把探索性分析写成预设分析；
- 输出文件是否能对应到 Analysis Plan 的 Result Item。

## 可复现运行包

必须包含：Analysis Plan、Dataset Version 引用、脚本、依赖锁定、运行命令、日志、Result Bundle、环境报告。
