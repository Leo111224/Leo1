# 稿件生成与合规规则

## IMRAD

- Introduction：证据现状、明确空白和研究目标；不预告结果。
- Methods：与 confirmed Protocol 和真实 Analysis Plan 一致。
- Results：只描述预先定义或明确标记的探索性分析，不解释机制。
- Discussion：总结主要结果、与证据比较、解释、临床意义和限制。

## 引用语法

- 数值：保存 `{display, result_ref:{result_id,run_id,version}}`。
- 文献：保存 `{statement_id,evidence_id,source_location}`。

## 报告规范路由

RCT→CONSORT；观察性研究→STROBE；系统评价→PRISMA；预测模型→TRIPOD。读取最新规范时记录来源日期。

## 导出闸门

检查数值引用、证据引用、Methods/Results 一致性、图表引用、未解决标记和用户批准状态。
