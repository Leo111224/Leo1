CORE LOGIC

用户意图不是关键词匹配，而是阶段、材料、任务和风险的组合判断

Agent 首轮需要先识别用户处于哪个科研阶段、手里有哪些材料、真正想完成什么任务，再决定主 Skill、辅助 Skill、是否需要追问，以及是否进入 R2/R3 强确认。

1. 判断阶段启动、设计、执行、统计、写作、投稿、录用后或通用问题
2. 检查资产方向、PICOS、Protocol、数据、结果、初稿、审稿意见
3. 路由 Skills选择主 Skill，并补调上游或下游辅助 Skill
4. 交付产物输出草案、清单、报告、版本化数据或正式投稿材料

8 STAGES

8 类用户科研状态与 Agent 路由

每个阶段都对应不同的真实诉求、优先追问、主调用能力与交付物。下面展示汇报版摘要和代表性问题。

STAGE 01

零基础启动期

9问题
核心诉求快速评估发文可行性，找到门槛最低、周期最短的路径。主调用总编排 + F-01 选题规划风险R1交付发文可行性评估、路径建议、周期预估
时间周期路径选择职称认定
  • 哪种类型的论文最好发、最快产出？
  • 还有 X 个月截止，现在开始准备来得及吗？
  • 能不能推荐一个工作量小、容易中的选题？
STAGE 02

选题与方案设计期

24问题
核心诉求确定适配数据的研究设计，验证创新性、可行性和合规边界。主调用F-01 选题规划 + F-03 研究设计风险R1/R2交付PICOS、研究方案、样本量判断、伦理清单
PICOS样本量研究设计伦理边界
  • 回顾性队列和病例对照研究该选哪个？
  • 纳入排除标准怎么定才合理？
  • 回顾性研究要不要过伦理？
STAGE 03

数据收集与预处理期

15问题
核心诉求完成合规收集、质量控制和结构化整理，形成标准分析集。主调用F-05 研究执行 + F-06 数据清洗风险R2交付招募/随访计划、数据字典、清洗计划、分析数据集
数据质控脱敏合规缺失异常随访管理
  • 用 Excel 录数据行不行？
  • 患者信息怎么脱敏才合规？
  • 缺失值直接删掉还是填补？
STAGE 04

统计分析攻坚期

17问题
核心诉求选对统计方法，正确解读结果，并规范呈现图表。主调用F-07 算法推荐 + F-08 统计分析风险R2/R3交付Analysis Plan、Verified Result、统计解释、图表方案
方法选择结果解读阴性结果统计图表
  • 找危险因素用 Logistic 还是 Cox 回归？
  • 阴性结果还能发论文吗？
  • 统计结果怎么整理成规范的表格和图？
STAGE 05

论文撰写打磨期

25问题
核心诉求写出结构完整、逻辑清晰、重复率合规且突出研究价值的论文。主调用F-10 报告生成风险R3交付IMRAD 初稿、摘要、讨论、图表说明、合规声明
标题摘要方法结果讨论局限查重降重
  • 标题怎么写能吸引编辑、提高初审通过率？
  • 讨论怎么写才不会重复结果部分？
  • 伪造参考文献会不会被发现？
STAGE 06

投稿与同行评审期

23问题
核心诉求精准匹配期刊，应对返修/拒稿，提高录用概率并控制时间成本。主调用F-12 期刊推荐 + F-10 报告生成风险R3交付期刊梯队、投稿包、Cover Letter、审稿回复矩阵
选刊投稿包催稿返修拒稿
  • 我的文章适合投哪些期刊？
  • 投稿 X 个月没消息正常吗？
  • 拒稿后能不能马上改投？
STAGE 07

录用后成果落地期

17问题
核心诉求完成出版、见刊、检索证明和评审/结题材料准备。主调用F-12 期刊推荐风险R3交付版权/APC/清样清单、检索证明、成果使用材料
版权协议版面费清样检索证明
  • 签了版权协议自己还能用文章吗？
  • 版面费能不能用科研经费报销？
  • 见刊和检索是不是一回事？
STAGE 08

全周期通用类

12问题
核心诉求消除决策顾虑，明确服务边界、时间、成本、风险和信任基础。主调用总编排风险R0/R1/R3交付服务边界说明、周期风险预估、下一步行动建议
加急成功率保密合规边界
  • 能不能全程加急？最快多久？
  • 整体成功率大概多少？
  • 会不会涉及学术不端？
INTENT TYPES

8 类细分意图与处理策略

同一个问题可能来自不同阶段，Agent 需要根据“当前材料”决定是解释、追问、生成草案，还是进入强确认。

时间周期 / 交付路径

最快多久、来不来得及、能不能加急。先评估截止时间和已有材料，再给可行路径。

总编排 / F-01 / F-12

选题方案 / 方法设计

选什么题、队列还是病例对照、样本量够不够。先构建 PICOS，再评估可行性。

F-01 / F-02 / F-03 / F-04

伦理合规 / 注册材料

伦理怎么做、是否知情同意、临床注册怎么填。只生成草案，不替代审批。

F-04 / F-03 / F-10

数据治理 / 执行质控

Excel、录入、缺失、异常、随访。先确认授权和数据字典，再画像与版本化。

F-05 / F-06 / F-07

统计分析 / 结果呈现

用什么统计、P 值怎么解释、阴性结果怎么办。正式结果必须来自 Verified Result。

F-07 / F-08 / F-09

论文写作 / 文稿优化

标题摘要、引言讨论、查重降重。基于真实结果和引用写作，阻断无来源数值。

F-10 / F-02 / F-11

投稿发表 / 成果落地

选刊、返修、拒稿、版权、检索证明。匹配最新规则，生成投稿与接收后清单。

F-12 / F-10 / F-11

服务信任 / 规则解释

成功率、费用、认不认、是否合规。明确边界，不承诺录用或违规操作。

总编排 / F-12 / F-04
ROUTING RULES

Agent 入口路由规则

这些规则可以直接同步到总编排 Agent，用来控制首轮追问、工具调用和风险确认。

先问阶段不要一上来回答，先判断用户处于启动、方案、执行、统计、写作、投稿还是录用后。
先查资产题目、PICOS、Protocol、数据、结果、初稿、审稿意见会决定路由路径。
强确认边界研究设计、伦理、数据清洗、统计执行、正式导出和投稿外发均需确认。
结果要溯源P 值、HR/OR、图表和论文 Results 必须来自 Verified Result 或可追溯来源。
不承诺录用对最快、最好发、成功率等问题，只能给路径和风险，不能保证结果。
